# Posiflora Admin — карта навигации и возможностей (1:1 спецификация для клона)

> Источник: боевой контур `https://floreii.posiflora.com/admin/*` (аккаунт somova).
> Цель: фронтенд/навигация клона `floree` должны повторять структуру 1:1.
> Снято: 2026-06-29. Код по этой спеке пишет Sonnet-агент.
>
> Легенда: `[Топ]` / `[New]` — бейджи у пункта меню в Posiflora.
> Каждый раздел: **маршрут** → **назначение** → **элементы/возможности**.

---

## 0. Глобальный layout

- **Левый сайдбар** (фиксированный, тёмный). Логотип POSiFLORA сверху → ведёт на `/admin/retail-stores`.
  - Кнопка-гамбургер сворачивает сайдбар.
  - Группы меню работают как **аккордеон**: одновременно раскрыта только одна группа верхнего уровня. Внутри групп есть вложенные подгруппы (тоже аккордеон).
- **Верхние CTA в сайдбаре:**
  - `Создать новую точку +` → внешняя ссылка WhatsApp (заявка менеджеру). В клоне — заменить на реальную форму или убрать.
  - `Увеличить выручку 💰` → промо `/admin/wallet-cards-promo`.
- **Шапка (верхняя панель):**
  - Блок «Персональный менеджер» (аватар + имя).
  - Бейдж `Забрать 10 000 ₽` (реферальное промо).
  - `23 дня до конца подписки` + кнопка `Оплатить` → `/admin/redirect-to-billing`.
  - Имя пользователя `somova` + выпадающее меню (профиль).
  - Колокол уведомлений `notifications_active` с счётчиком (10).
  - `Поддержка`.
- **Низ сайдбара:** промо-баннеры (онлайн-витрина, СБП), `Выйти из системы` → `/admin/logout`.

### 2.1. Аналитика (дашборд) — `/admin/retail-stores`

**Назначение:** стартовый дашборд торговой точки («Floree»). Сводка по деньгам, клиентам, витрине, складу.

**Шапка страницы:**
- Заголовок = название точки («Floree»), ссылка `Инструкция`, ссылка `Настройки точки продаж`.
- Справа — **выбор периода** (date range, по умолч. текущий месяц, напр. «1 июн. 2026 — 30 июн. 2026»).
- Подпись «Данные обновлены: <дата/время>».

**4 вкладки-переключателя (каждая = отдельный маршрут/под-аналитика):**
1. `Деньги` → остаётся на `/admin/retail-stores`.
2. `Клиенты [НОВОЕ]` → `/admin/customers/analytic`.
3. `Букеты в магазине` → `/admin/showcase/analytics`.
4. `Склад` → `/admin/warehouse/analytics`.

**Вкладка «Деньги» — виджеты:**
- Карточки с динамикой (%) к прошлому периоду: `Выручка по отгрузке` (+Подробнее), `Выручка по оплате`, `Валовая прибыль`.
- Таблица по сотрудникам: `Сотрудник | Средний чек | Продажи | Доля`.
- Карточки: `Заказы`, `Средний чек`, `Возвраты`, `Возвраты в деньгах`, `Напечатано чеков`, `Суммарная скидка` (+Подробнее), `Маржинальность бизнеса за период` (+Подробнее).
- **Покупатели → Способы оплаты:** список метод/сумма/доля (Наличные, Безнал, Перевод на т-банк, Я-Пэй СБП Табличка, Карта, Я-Пэй СБП Ссылка).
- **Источники сделки:** Терминал / Телефон (сумма + доля).
- **Обязательства → Грядущие заказы на неделю:** мини-календарь 7 дней с количеством заказов; `Принято авансов`, `Бонусов накоплено`, `Долг клиентов`, `Бюджеты в грядущих заказах`, `Заказов в долг`.

**Вкладка «Клиенты» = `/admin/customers/analytic`:**
- **Сегментация клиентов** — 4 карточки с кнопкой `Отправить Push/SMS` на каждой:
  - `Разовые покупатели` (совершили 1 покупку),
  - `Без покупок` (есть в базе, ни разу не покупали),
  - `Риск оттока` (2+ покупки, не активны >12 мес),
  - `Активные постоянные` (5+ заказов, активны в течение года).
- `+N клиентов добавлено в базу`, `N% заказов закрыто с привязанным клиентом`.
- **Покупатели** — таблица `Тип клиентов | Продажи | Средний чек | Доля продаж` (Постоянные / Новые / Обезличенные).
- **Продажи по сегментам** — график динамики (Постоянные/Новые/Обезличенные).
- **Бонусная система** — эффективность %, `Бонусов накоплено/потрачено клиентами` (+Подробнее), `N клиентов за все время`, `N бонусов всего в системе`, `N событий в базе`, `% карточек содержат события`.

**Вкладка «Букеты в магазине» = `/admin/showcase/analytics`:**
- Карточки: `выручка по отгрузкам`, `средняя стоимость букета`, `маржинальность витрины`, `букетов продано`, `продано с доставкой`, `букетов в день в среднем`.
- Графики: `Продажи букетов по дням`, `Продажи внутри дня`.

**Вкладка «Склад» = `/admin/warehouse/analytics`:**
- **Сумма закупок по приходным накладным** — таблица `Категории | Сумма накладных` (Цветы / Упаковка / Декор / Итого).
- **Списания по причинам** — `Все списания | Сумма | Доля` (Порча, Согласно акту инвентаризации, …) + `Сумма списаний`.
- **Списанные товары** — топ-10 за период (`Сумма | Количество`), фильтр по причине.

### 2.2. Заказы — `/admin/orders`

**Назначение:** список всех заказов с фильтрацией, поиском, массовыми действиями, агрегатами.

**Верхняя панель:**
- Кнопка `Создать новый` → форма нового заказа.
- Кнопка `Скачать найденные` (экспорт отфильтрованного списка).
- Поле поиска: placeholder «Номер, клиент, состав заказа…».

**Вкладки по статусам (с счётчиками):**
`ВСЕ (54)` · `НОВЫЕ (1)` · `СОБРАННЫЕ (0)` · `ОТМЕНЁННЫЕ (9)` · `ЗАВЕРШЁННЫЕ (44)` · `ВОЗВРАТ (0)` · `КРЕДИТ (0)` · `У КУРЬЕРА (0)`

**Левая панель фильтров («Фильтр заказов»):**
- `ДАТА ИСПОЛНЕНИЯ` — диапазон дат (по умолч. неделя, напр. 22.06.2026 — 29.06.2026).
- `ДАТА СОЗДАНИЯ` — селект периода (Весь период / …).
- `ДАТА ЗАКРЫТИЯ` — селект периода.
- `ИСТОЧНИК` — селект (Все источники).
- `КЕМ СОЗДАН` — селект флориста (Все флористы).
- `ТОРГОВАЯ ТОЧКА` — селект (Все точки).
- `КЕМ ЗАКРЫТ` — селект флориста.
- `ФЛОРИСТ` — селект флориста.
- `Детали оплаты` — раскрываемая секция (доп. фильтры по оплате).
- Кнопки `Применить фильтр`, `Сбросить фильтры`. Подпись «Найдено заказов: N».

**Таблица — колонки:**
`№` (ссылка на заказ) · `Статус` · `Клиент` (имя + телефон, ссылка на карточку клиента) · `Дата/Время создания` (+ город, GMT) · `Автор заказа` · `Дата/Время завершения` · меню действий `⋮` (more_vert) в каждой строке.
- Кнопка `Столбцы` — настройка видимых колонок.

**Низ таблицы / пагинация:**
- `Кол-во на странице`: селект (25 / …).
- «1 - 25 из 54», переход на страницу, кнопки страниц `1 2 3`, стрелки.

**Агрегаты под таблицей (итоги по выборке):**
`Сумма заказов` · `Бюджет` · `Оплачено` · `Кредит` · `Бонусы` · `Скидка` · `Надбавка`.

**Действия по строке (`⋮` more_vert):** Angular Material `mat-menu` в CDK-overlay. На странице заказов кнопка **disabled для терминальных статусов** (Завершённые/Отменённые) — меню доступно только для активных заказов (Новые/Собранные/У курьера). Пункты зависят от статуса (смена статуса / печать / отмена) — уточнить на активном заказе.

> Общий паттерн меню `⋮` во всех таблицах: пример со страницы **Поставщики** — пункты `✏️ Редактировать` и `⊗ Удалить`. В справочниках/документах меню строки = Редактировать/Удалить (+ доп. действия по контексту).

#### 2.2.1. Карточка заказа — `/admin/orders/:id`

Заголовок: `← Назад`, `Заказ № <номер>`, бейдж статуса (справа, кликабельный для смены статуса). Две вкладки: **Общая информация** и **Продукты**. Кнопка `Скачать` (экспорт/печать).

**Вкладка «Общая информация»:**
- `Точка продаж` — название + адрес.
- `Клиент` — таблица Имя / Электронный адрес / Телефон (имя и телефон — ссылки на карточку клиента).
- Блок доставки: `Самовывоз` или `Доставка` (адрес, время).
- `История статусов` — таблица `Статус | Дата обновления статуса | Исполнитель` (напр. Новые → Собранные → У курьера → Завершённые).

**Вкладка «Продукты»:**
- `Пожелания клиента` → `Комментарий к заказу`.
- `Состав заказа` — таблица `Наименование | Цена | Количество | Единица измерения | Сумма`. Иерархия: строка-букет (родитель) + вложенные компоненты (упаковка, цветы, доставка). У компонента: исходная цена (зачёркнута) и итоговая, множитель кол-ва (`3,00 x 1`).
- `История платежей` — таблица `Способ оплаты | Дата | Фискализация аванса | Сумма` + `ИТОГО`.
- **Итоговая панель:** `ПРОДУКТОВ`, `БУКЕТОВ`, `ИТОГО`, `СКИДКА` (в т.ч. на цветы / на букеты / на заказ), `НАДБАВКА` (в т.ч. …), `ОПЛАТА БОНУСАМИ`, `АВАНСЫ`, `ОБЩАЯ СТОИМОСТЬ ЗАКАЗА`, индикатор `ЗАКАЗ ОПЛАЧЕН`.

> ⚠️ Здесь живёт уязвимость с ценой (см. [[payment-price-vuln]]): цена позиций приходит с клиента. В клоне цену пересчитывать на сервере.

#### 2.2.2. Создание заказа — `/admin/orders/create`

Заголовок `Новый заказ`, `← Назад`. Кнопки внизу: `Создать заказ`, `Отмена`.

- **Точка продаж \*** — select (обязательно).
- **Клиент:**
  - `Имя клиента` — select существующего; ссылка `+ Создать нового клиента`.
  - `Источник сделки \*` — чипы выбора: `AmoCRM`, `Сайт`, `Телефон`, `Терминал`, `+` (добавить источник; справочник `customer-deal-sources`).
- **Детали заказа:**
  - `Бюджет` — число.
  - `Текст комментария` — textarea (лимит 500).
  - `Быстрые теги` — чипы (Моно, Маленький, WOW эффект, Заказ от собственников, Нежный, Большой, Девушке, Маме, Бабушке, `+`). Справочник `order-tags`.
  - `Изображения` — загрузка (jpg/jpeg/png, ≥100×100, до 10 МБ; первое — главное).
- **Формирование ссылки СБП** — промо подключения Яндекс.Пэй СБП.
- **Авансы** — `+ Добавить аванс`.
- **Получение заказа** — переключатель `Самовывоз` / `Доставка`.
- **Когда выполнить заказ** — `Сегодня` / `Завтра` / `Послезавтра` / `Другая дата`.

> Состав товаров/букетов добавляется через каталог/витрину; цены позиций — см. ⚠ выше.

### 2.3. Букеты и каталог

> Подписи меню: «Букеты в магазине» = `/admin/showcase`; «Онлайн-витрина [Топ]» = `/admin/shop-settings`; «Рецепты» = `/admin/specifications` (внутренне «спецификации», JSON:API сущность specification).

#### 2.3.1. Букеты в магазине — `/admin/showcase` (→ `/admin/showcase/bouquets`)

Физическая витрина точки (собранные букеты в наличии).
- Заголовок = точка «Floree» (dropdown выбора точки) + адрес.
- Сводка-вкладки: `N букетов на витрине` (диапазон цен + Сумма) | `Цветы и расходники в букетах` (N стеблей).
- Кнопка `Распечатать все штрихкоды`.
- `Сортировать`: по цене / по названию / по новизне; фильтр `Флорист`; поиск по номеру/названию.
- Сетка карточек букета: фото, бейдж цены, бейдж срока годности («3 дня»), название, `Собран <дата> <флорист>`, `№<номер>`, ссылка `Разобрать букет`, кнопка `Распечатать штрихкод`.

#### 2.3.2. Онлайн-витрина — `/admin/shop-settings` `[Топ]`

Интернет-магазин на базе POSiFLORA (платная фича, **не подключена** на этом аккаунте).
- Лендинг-апселл: «Ваш интернет-магазин», `2790 ₽ в месяц`, кнопка `Запустить в 1 клик`, ссылка вида `floreii.posiflora.com`.
- В клоне: настоящая страница настроек storefront (домен, оформление, email уведомления, мобильная версия).

#### 2.3.3. Аналитика витрины — `/admin/showcase/analytics`
См. раздел 2.1 (вкладка «Букеты в магазине»).

#### 2.3.4. Каталог товаров и услуг — `/admin/catalog`

Список всей номенклатуры (товары/услуги). 347 позиций.
- Кнопки: `Создать продукт`, `Экспортировать продукты`, `Сгенерировать штрих-коды`.
- Справа: select `Укажите категорию`, поиск `Укажите название, артикул…`.

## 3. Сводка для реализации (чек-лист маршрутов клона)

Все маршруты под префиксом `/admin`. Группы — аккордеон (одна открыта). Документные списки имеют единый паттерн: фильтр (точка/период) + кнопка создания + таблица + пагинация + настройка колонок (⚙/`Столбцы`). Справочники — чип-список / таблица / форма.

Ключевые сущности JSON:API (см. также api-map.md на сервере): orders, order-payments, specifications (рецепты) + variants, categories, bouquets (витрина), customers, stores (retail-stores), warehouses, shifts, cash, roles, workers, vendors, reports, order-sources/deal-sources, bonuses, discounts, wallet-cards.

⚠️ При реализации заказов сразу закрыть уязвимость с ценой (цену позиций считать на сервере) — см. раздел 2.2.1.
